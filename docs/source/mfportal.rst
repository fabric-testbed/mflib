
MFPortal
========

MFPortal wires an experiment slice onto a FABNetv6 measurement network and
registers it with the mfportal service -- adding/assigning FABNetv6 meas
networks, mfuser account setup, meas-node self-start, and portal
registration. See ``MFPORTAL_METHODS.md`` in the repository root for a
narrative method-by-method reference.
