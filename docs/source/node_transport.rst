
Node Transport
==============

``RestNodeAdapter`` maps MFLib's node operations (execute, upload/download
files) onto a REST API, so ``MFLib``/``Core`` can talk to a measurement
node over plain HTTP instead of requiring a live FABlib slice/SSH
connection.
